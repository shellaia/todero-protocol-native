Todero Protocol Native Governance

The Todero Protocol Native project has a single canonical implementation
maintained in this repository.

The maintainers are responsible for:
- defining protocol-native feature scope
- maintaining ABI and packaging compatibility guarantees
- publishing release artifacts and distribution metadata

Changes to core behavior, ABI expectations, artifact contracts,
or compatibility requirements must be proposed via pull requests
and approved by maintainers.

Forks are permitted under the Apache License 2.0,
but this repository defines the authoritative reference
implementation for Todero protocol-native artifacts.
